# RefursWM

Тайлово-скроллинговый Wayland-композитор на Zig поверх wlroots 0.20.

- **dwindle** — логика деления окон как в Hyprland: новое окно делит окно в фокусе пополам по длинной стороне.
- **scroll** — бесконечная горизонтальная лента колонок (как niri/PaperWM); лента сама подъезжает к окну в фокусе.
- Режим переключается для каждого рабочего стола отдельно (`Super+Tab`), окна сохраняются.

## Почему быстрый

- Ноль работы в простое: нет таймеров, нет опроса, нет IPC-сокета, нет парсинга конфига. Код выполняется только в ответ на событие от клиента или устройства ввода. Замер в headless: **0 тиков CPU за 10 секунд простоя**.
- Рисует wlr_scene с учётом повреждений: перерисовываются только изменившиеся пиксели, полностью перекрытые окна не получают кадров. Непрозрачное полноэкранное окно идёт на экран напрямую (direct scanout), без композитинга.
- Тайловое окно получает свой итоговый размер ещё до первой отрисовки: нет «прыжка» размера и лишнего буфера на каждое новое окно.
- Повторные configure, клипы и позиции не отправляются, если ничего не изменилось.
- Бинарник ~250 КБ, RSS ~17–20 МБ (из них основная часть — wlroots и буферы вывода).

## Безопасность

- Нет Xwayland (в X11 любое окно читает клавиатуру и экран остальных).
- Привилегированные протоколы выключены по умолчанию: захват экрана, фоновый доступ к буферу обмена, виртуальная клавиатура/мышь, гамма. Включаются флагами в `config.zig`.
- Даже включённые, они — а также layer-shell и блокировка экрана — скрыты от sandbox-клиентов (flatpak и др. через `security-context-v1`).
- Блокировка экрана `ext-session-lock-v1`: все мониторы закрываются непрозрачным слоем до того, как локер получает «заблокировано». Если локер упал — экран остаётся заблокированным; работает только `Super+L` (запустить локер заново) и Ctrl+Alt+Fn.
- Хоткеи композитора не может перехватить приложение; отпускание клавиши хоткея тоже не уходит в приложение.
- xdg-activation: окно может забрать фокус только с токеном, созданным реальным действием пользователя.
- Программы запускаются через `posix_spawnp` напрямую, без shell; в новой сессии, со сброшенными сигналами.
- Сборка по умолчанию ReleaseSafe (проверки границ и переполнений остаются), PIE, full RELRO, BIND_NOW, неисполняемый стек.

## Сборка

Нужны: Zig 0.17, wlroots 0.20, wayland, wayland-protocols, xkbcommon, libinput, pixman, pkg-config, wayland-scanner.

На Void:

```bash
doas xbps-install -S wlroots0.20-devel wayland-devel libxkbcommon-devel libinput-devel pixman-devel pkg-config
```

```bash
zig build --prefix ~/.local
```

Со скруглёнными углами (подключает scenefx, рендерер GLES2):

```bash
doas xbps-install -S scenefx-devel
```

```bash
zig build -Dfx=true --prefix ~/.local
```

Тесты логики раскладок (работают на любой ОС):

```bash
zig build test
```

## Запуск

Из TTY (нужен `seatd` с пользователем в группе `_seatd`, либо elogind):

```bash
refurswm
```

`REFURS_DEBUG=1` — подробный лог wlroots. `REFURS_STARTUP="foot -e htop"` — запустить одну программу при старте (без shell, аргументы через пробел).

## Конфиг

Всё в [`src/config.zig`](src/config.zig): правишь → `zig build` → перезапускаешь. Ошибка в конфиге — это ошибка компиляции, а не сюрприз после входа.

Что там есть: тёмная и светлая палитры и команды при смене темы (по умолчанию `gsettings ... color-scheme`), толщина рамки, зазоры, радиус скругления, прозрачность активного/неактивного окна, режим по умолчанию, ширины колонок, фокус за курсором, раскладки xkb (`us,ru`, `grp:alt_shift_toggle`), тачпад, мониторы (масштаб, режим, позиция), правила окон (app_id/title → float, рабочий стол, прозрачность), автозапуск, хоткеи.

Хоткеи сравниваются по клавише первой раскладки без модификаторов, поэтому `Super+Q` работает и при включённой русской раскладке.

## Хоткеи по умолчанию

| Клавиши | Действие |
|---|---|
| `Super+Enter` | терминал (foot) |
| `Super+D` | лаунчер (fuzzel) |
| `Super+Q` | закрыть окно |
| `Super+Shift+E` | выйти |
| `Super+L` | заблокировать экран (swaylock) |
| `Super+стрелки` | фокус в сторону (и на соседний монитор) |
| `Super+Shift+стрелки` | переместить окно |
| `Super+Ctrl+стрелки` | изменить размер |
| `Super+Space` | плавающее / тайловое |
| `Super+F` | полный экран |
| `Super+Tab` | dwindle ⇄ scroll для этого стола |
| `Super+S` | dwindle: повернуть деление |
| `Super+R` | scroll: ширина колонки 1/3 → 1/2 → 2/3 → 1 |
| `Super+[` / `Super+]` | scroll: вложить окно в соседнюю колонку |
| `Super+\` | scroll: вынести окно в свою колонку |
| `Super+Shift+T` | тёмная ⇄ светлая тема |
| `Super+1..9` | рабочий стол |
| `Super+Shift+1..9` | отправить окно на стол |
| `Super+ЛКМ` (тянуть) | плавающее: двигать; тайловое: бросить на другое окно — поменять местами |
| `Super+ПКМ` (тянуть) | изменить размер |
| `Ctrl+Alt+F1..F12` | переключить VT |

## Протоколы

xdg-shell, layer-shell (панели, обои, лаунчеры), xdg-decoration (рамки рисует композитор), xdg-activation, xdg-output, viewporter, fractional-scale, presentation-time, single-pixel-buffer, linux-dmabuf, cursor-shape, relative-pointer, idle-notify, idle-inhibit, ext-session-lock, security-context, primary selection, drag-and-drop. По флагам конфига: wlr-screencopy и ext-image-copy-capture, data-control, virtual keyboard/pointer, gamma-control.

## Что проверено и что нет

Проверено в headless-режиме (Void, wlroots 0.20.2, pixman, без GPU) скриптами из [`tests/`](tests): dwindle, scroll, переключение режима, ресайз, полный экран, темы, рабочие столы, плавающие окна, split, колонки, фокус за курсором, layer-shell (swaybg, fuzzel), блокировка (включая упавший локер), чистый выход по SIGTERM, нагрузка в простое. Скрипты запускаются с бинарником, собранным с `-Dtesting=true` (он включает screencopy и виртуальный ввод для grim/wtype — не используйте его для работы).

Не проверено на реальном железе: DRM/KMS, libinput-тачпад, несколько мониторов, сборка `-Dfx=true` (компилируется; рисовать её в контейнере без GPU нельзя).

Не реализовано: Xwayland (намеренно), pointer-constraints (захват мыши в играх), планшеты и тач-экраны, индикатор рабочих столов для netline (netline говорит с IPC MangoWM, у RefursWM IPC нет).
